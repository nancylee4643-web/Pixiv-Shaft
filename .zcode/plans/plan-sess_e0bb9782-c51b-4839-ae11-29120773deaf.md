# 标签分组：收藏标签筛选列表的父-子标签折叠功能

## 背景与总体思路

「按标签筛选」（`BookedTagFeedFragment`，插画/小说收藏共用）目前是纯平铺标签列表。需求：允许用户配置父标签-子标签映射（如 原神→宵、神里绫华…），筛选列表中子标签折叠到父标签行下，缩短列表。

项目中「同义词词典」（issue #904，`ceui.pixiv.db.synonym` + `ceui.pixiv.ui.synonym`）是同类功能的完整模板：父子两级 Room 表、折叠树管理页、设置开关接线。**本功能语义独立（纯展示归组，不参与同义词匹配），新建独立表、UI 照搬该模式**，不污染同义词词典（词典在「按标签收藏」`SelectTagFeedFragment` 等处参与匹配）。

三部分：① Room 存储层；② 标签分组管理页；③ 筛选页分组折叠展示。

## 1. 存储层（新包 `app/src/main/java/ceui/pixiv/db/taggroup/`）

- `TagGroupEntity.kt` — 表 `tag_group_table`：`id`(PK 自增)、`name`(unique 索引)、`createdAt`。仿 `SynonymTargetEntity`。
- `TagGroupChildEntity.kt` — 表 `tag_group_child_table`：`id`(PK 自增)、`groupId`(加索引，不声明 FK 约束——对齐 synonym 做法，删除由 DAO 事务保证)、`name`(**unique 索引**：一个子标签只能归属一个父)、`createdAt`。仿 `SynonymTagEntity`。
- `GroupWithChildren.kt` — `@Embedded` group + `@Relation(groupId)` children，仿 `TargetWithSynonyms`。
- `TagGroupDao.kt` — 仿 `SynonymDao`：`getAllWithChildrenLive()`(LiveData，管理页与筛选页 observe)、同步版 `getAllWithChildren()`、`insertGroup`/`renameGroup`/`deleteGroupWithChildren`(@Transaction 先删子)、`insertChild`/`renameChild`/`deleteChild`、按名查重(大小写不敏感查重在 UI 层做)、`clearAll`。
- `AppDatabase.java`：
  - entities 注册两个新 Entity（version 注释 v42）；
  - `VERSION = 41 → 42`，新增 `MIGRATION_41_42`（两条 `CREATE TABLE IF NOT EXISTS` + 索引 SQL，照抄 `MIGRATION_35_36` 的写法，索引名须与 Room 约定一致 `index_tag_group_table_name` 等）；
  - 追加进 `ALL_MIGRATIONS`；加 `abstract TagGroupDao tagGroupDao();`；
  - 构建后提交生成的 `app/schemas/ceui.lisa.database.AppDatabase/42.json`（exportSchema=true，41.json 已入库）。

## 2. 标签分组管理页（新包 `ceui.pixiv.ui.taggroup`，仿 SynonymDict）

- `TagGroupFragment.kt`（`R.layout.fragment_tag_group`）：toolbar（返回 + 菜单「添加分组」）+ RecyclerView + 空态。经 `TemplateActivity` 路由：`case "标签分组": return new ceui.pixiv.ui.taggroup.TagGroupFragment();`（插在 `TemplateActivity.java:490` 同义词词典 case 旁）。
- `TagGroupViewModel.kt` — 仿 `SynonymDictViewModel` 但简化：`allGroups`(LiveData 来自 DAO)、`expandedGroupIds: MutableLiveData<Set<Long>>`、`displayItems: MediatorLiveData<List<DictItem>>`（sealed：`Group(entity, childCount, expanded)` / `Child(entity)`）。用户自建数据量小，**主线程 rebuild 即可**，不需要 synonym 的后台 executor。
- Adapter（Fragment 内部，仿 `DictAdapter`）：Group 行 = 名字 + 子标签数徽章 + chevron（点行体弹菜单：添加子标签/重命名/删除分组；点 chevron 区域折叠展开，箭头旋转动画照抄 `TargetVH`）；Child 行 = 缩进 + 导轨（仿 `item_synonym_tag.xml`），点击弹编辑/删除。
- `TagGroupOperate.kt` — 输入弹窗封装（添加分组/添加子标签/重命名），校验：非空、不含空格（pixiv 标签分隔符）、与现有父/子标签名不重复——对齐 `SynonymOperate` 的校验规则。
- 布局：`fragment_tag_group.xml`、`item_tag_group.xml`、`item_tag_group_child.xml`（参考 `fragment_synonym_dict.xml`、`item_synonym_target/tag.xml`）。
- 字符串：`tag_group_*` 系列（标题「标签分组」、添加分组、添加子标签、重命名、删除确认、子标签数等），按 `synonym_dict_*` 的先例补齐 values(默认)/en/ja/zh-rTW/ko/ru/tr。

## 3. 筛选页分组展示（改 `BookedTagFeedFragment.kt`）

新增两个 FeedItem 类型（feeds 框架按 item 类选 renderer，`FeedAdapter.kt:46`）：
- `BookedTagGroupItem(parent: TagsBean, children: List<TagsBean>, expanded: Boolean)`，feedKey `"group:${parent.name}"`；父标签不在收藏标签里时用本地合成的 `TagsBean(name=父名, count=-1)`，count=-1 在此类型内仅表示「计数留空」。
- `BookedTagChildItem(tag: TagsBean)`，feedKey `"tagchild:${tag.name}"`。
- `BookedTagFeedItem` 原样保留（两个虚拟行 + 未分组标签）。

`onCreateRenderers()` 返回 3 个 renderer（`BookedTagFeedFragment.kt:145`）：
- 原 `bookedTagRenderer` 不动；
- 组头 renderer（新布局 `recy_book_tag_group.xml`：卡片行 `#父名/译名` + 自身作品数（count==-1 留空）+ 「N个子标签」徽章 + chevron）。**行体点击 = 按父标签名发 FILTER_ILLUST/FILTER_NOVEL 广播 + finish()（与普通标签完全一致）；chevron 区域点击 = 折叠/展开**——对齐 SynonymDict 的「行体动作 / 热区展开」分工；
- 子行 renderer（新布局 `recy_book_tag_child.xml`：缩进 + 导轨），点击 = 按子标签名广播 + finish()（复用现有广播代码，抽成小函数共用）。

展示管线（核心重构）：`applyFilter()`（L205）改造为统一的 `rebuildDisplay()`，输入 = `fullList`（不动，L86 捕获逻辑保持）+ 映射表 + 展开状态 + 搜索词，输出经 `feedViewModel.mutateItems {}` 提交：
- **无搜索**：`[未分類, 全部]` + 按原 API 顺序遍历真实标签——已配置为子标签的跳过；父标签出现处插入 GroupItem（父不在列表时，在其第一个子标签出现处插入合成父行，计数留空）；expanded 时其后跟 ChildItem 列表（保持原相对顺序）；**默认全部折叠**。父标签存在但其子标签全不在收藏里 → 该父仍按普通标签行显示（不出 chevron）。
- **有搜索**：隐藏虚拟行；父命中 → 父行 + 全部在列表中的子行（自动展开标记）；仅子命中 → 父行 + 命中的子行；保持从属关系与缩进——完全对齐 `SynonymDictViewModel.rebuild()`（L88-101）的搜索规则。
- 映射数据源：`tagGroupDao().getAllWithChildrenLive()` 由 viewLifecycleOwner observe，任何变动（含从管理页返回）自动触发 `rebuildDisplay()`；`Shaft.sSettings.isTagGroupEnabled == false` 或映射为空时输出与现状逐字节一致（纯平铺）。
- 展开状态：Fragment 内 `MutableSet<String>`（父标签名），toggle 后 `rebuildDisplay()`；点击标签后 activity finish，无需跨会话持久化。
- 插画/小说（type 0/1）同一 Fragment，映射按标签名全局共用，小说侧自动生效；接收端 `LikeIllustFeedFragment`/`LikeNovelFeedFragment` 零改动（仍是单标签服务端过滤）。

## 4. 设置接线

- `Settings.java`：`tagGroupEnabled`（boolean，**默认 true**——建了映射即生效，开关作临时停用）+ getter/setter（仿 L412/1283 synonymDictEnabled）。
- `fragment_settings_bookmarks.xml` + `FragmentSettingsBookmarks.java`：仿 browsing 页 synonym 两行（`fragment_settings_browsing.xml:460-500`）加「标签分组」开关行 + 「管理标签分组」入口行（开关关闭时入口行 GONE，对齐 synonym）；入口 `startActivity(TemplateActivity, EXTRA_FRAGMENT="标签分组")`。
- `SettingsCatalog.kt`：BOOKMARKS 分类加两条 Entry（含搜索关键词「标签 分组 折叠 父 子 tag group」，仿 L134-135）。
- `BookedTagFeedFragment` toolbar：开关开启时加「标签分组」菜单项跳管理页（照抄同义词词典菜单项 L105-113 的写法）。

## 5. 验证

- 把纯逻辑抽成顶层函数 `buildGroupedDisplay(tags, groups, expandedNames, query): List<FeedItem>`，在 `app/src/test` 加单元测试：无映射回退平铺 / 父在列表 / 父不在列表（合成行、插入位置）/ 父在但子全不在（退化普通行）/ 搜索父命中、仅子命中 / 折叠与展开 / 虚拟行随搜索隐藏。
- `gradlew :app:compileClassicDebugKotlin`（或当前 flavor 等价任务）编译通过 + 跑新增单测；迁移用 `MigrationTestHelper` 不强求（项目未见迁移测试先例，手动覆盖安装验证即可）。
- 手动路径：设置→收藏与互动→标签分组→添加「原神」+子标签→按标签筛选页看到折叠组→展开/搜索/点击父/点击子→收藏列表按所选标签过滤。

## 非目标（本次不做）

- 不影响「按标签收藏」（`SelectTagFeedFragment`）与同义词词典匹配逻辑；
- 不做导入/导出备份（后续可按 `SynonymDictBackup` 模式补）；
- 不改筛选结果列表本身（服务端单标签过滤维持不变）；不支持「一键筛父标签或全部子标签」之类组合过滤。
